# Vaultify: Student-Centric Expense & Budget Management Tracker

## 🚀 Project Overview
Vaultify is a smart expense and budget tracking web application designed specifically for college students to manage monthly allowances, track daily micro-expenses, and learn smart financial planning habits.

Access the live website here: [Vaultify Google Site](https://sites.google.com/view/vaultify-tracker/home)

## ✨ Key Features
* **Smart Budgeting Calculator:** Implements the 50/30/20 rule for managing essentials, wants, and savings.
* **Daily Expense Logger:** Seamlessly logs transactions via Google Forms connected to a cloud database.
* **Student Financial Tips & FAQ:** Curated financial guidelines tailored for college students.
